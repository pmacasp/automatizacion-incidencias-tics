# Automatización de incidencias TICS

Aplicación desarrollada en Python para validar, procesar y generar indicadores
a partir de incidencias tecnológicas registradas manualmente en un archivo CSV.

## Objetivo

Automatizar la validación, clasificación y generación de reportes de incidencias
tecnológicas reportadas por las diferentes áreas municipales.

## Tecnologías

- Python
- Pytest
- Coverage
- Git
- GitHub Actions
